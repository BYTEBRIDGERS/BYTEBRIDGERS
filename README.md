# BYTEBRIDGERS

## Online Coding and Evaluation Platform

BYTEBRIDGERS is a collaborative software engineering project focused on building an online platform for programming problem solving, code execution, automated evaluation, and submission tracking.

## Core Components

- **P1 — Frontend:** User interface, problem browsing, code submission, and dashboard.
- **P2 — Backend:** Spring Boot REST APIs, authentication, submission management, and MySQL persistence.
- **P3 — Code Execution:** Executes submitted programs and returns execution results.
- **P4 — Evaluation:** Evaluates execution results and produces submission verdicts.

## Technology Stack

- Java and Spring Boot
- MySQL
- HTML, CSS, and JavaScript
- REST APIs
- Git and GitHub
- Code execution and evaluation services
